# Tessera — notes for coding agents

Self-hosted link-in-bio page made of draggable widgets. `page.json` → one static, prerendered HTML file. Visual editor at `/#edit`. **Zero npm dependencies** — keep it that way (vanilla JS/CSS, Node ≥ 18 for scripts).

## Commands

```bash
npm run dev            # http://localhost:5173 (editor: /#edit) — also the editor's local backend
npm test               # smoke tests: every widget × size renders, feed parser, build
npm run build          # dist/index.html + dist/assets
npm run build:single   # one file, local assets inlined
TESSERA_PAGE=other.json npm run dev     # serve/edit another page file
```

Visual checks: build with `--inline-assets`, open `dist/index.html` in a headless Chrome (Playwright) and screenshot. External hosts (tiles, YouTube) may be blocked in sandboxes — that's expected, widgets fall back.

## Branches

- `main` — the open-source project + demo `page.json`. No personal content.
- `thibault` — Thibault's own page (`page.json`, `assets/uploads/`, `netlify.toml` with `TESSERA_URL`). Deployed by Netlify (project `tessera-clawfire`, auto-deploys this branch). Code changes go to `main` first, then `git merge main` into `thibault`.

## Architecture

Classic scripts sharing `window.Tessera` (no modules: the build inlines them into one file). Load order matters (see `src/index.html` and `SCRIPTS` in `scripts/build.mjs` — keep both in sync when adding a file):

| File | Role |
|---|---|
| `src/i18n.js` | `T.tp()` page strings (follow `settings.lang`), `T.te()` editor strings (browser lang), `T.L('English\|Français')` inline labels — use `\|\|` as separator when the text itself contains `\|` |
| `src/widgets.js` | `T.util` helpers (`esc`, `safeUrl`, `md`, `platform`, embeds…) + widget registry `def(type, {...})` |
| `src/render.js` | `T.pageHtml()` (pure), `T.render()`, theme vars, countdown, `.ics`, global handlers |
| `src/maps.js` | MapLibre (vendored in `assets/vendor/maplibre`) + OpenFreeMap; `theme` style generated from page colours |
| `src/youtube.js` | YouTube Music playlist view + own queue (skips unavailable tracks via IFrame API `onError`) |
| `src/assets.js` | Image uploads: resize/WebP in browser; local mode → dev server, hosted mode → IndexedDB until publish |
| `src/publish.js` | One commit (page.json + pending images) via GitHub git-data API or Gitea/Forgejo contents API |
| `src/editor.js` | `#edit` mode: drag & drop, panel forms generated from widget `fields`, undo, drafts |
| `src/app.js` | Boot: reads inlined `#page-data` or fetches `page.json` |
| `scripts/build.mjs` | Prerenders with the same code in `node:vm`, inlines CSS/JS/data, bakes YouTube playlists, SEO/OG meta |
| `scripts/dev.mjs` | Static server + `/__tessera/{ping,upload,save,youtube-playlist}` (127.0.0.1 only, same-origin POSTs) |
| `scripts/lib/youtube.mjs` | Playlist RSS parser (optional `YT_API_KEY` for >15 tracks) |

## Rules that bite

- **`render()` must be pure** (string in → HTML string out, no DOM): it also runs in Node at build time.
- **Escape everything**: `esc()` for text/attributes, `safeUrl()` for URLs (blocks `javascript:`; allows `blob:` for pending uploads). Never interpolate raw props.
- **Don't shadow helpers**: a local `const img = …` inside a widget once caused a TDZ crash (`img` is a helper in widgets.js).
- **Sizes** are `c×r` in a grid of half-rows (`U.SIZES`); the first size in `sizes` is the default and the fallback when a saved size is no longer allowed.
- **One grid per section**: `pageHtml` splits widgets at `section` widgets so `grid-auto-flow: dense` never pulls cards across sections.
- **Third-party CSS loads after ours** (e.g. `maplibre-gl.css` sets `.maplibregl-map{position:relative}`) → prefix our selectors (`.w-map .mapgl`) to win specificity.
- **Embed code** runs in a `data:` URL iframe (opaque origin: no access to the page, its storage/token). Don't switch to `srcdoc`+`sandbox` — sandbox flags propagate to the snippet's own iframes and break Ghost/Tally/Calendly.
- **Iframes** send `referrerpolicy="strict-origin-when-cross-origin"` — YouTube rejects embeds without a referrer (error 153).
- **Drafts** live in `localStorage` under `tessera:draft:v2:<pathname>` and are tied to a hash of the published JSON; the publish token is in session/local storage, never in `page.json`.
- New widget field types are generated by `field()` in `editor.js`; image fields use `image: true` (or `images: true` for line lists).

## Conventions

- JS: 2 spaces, single quotes, `'use strict'`, small comments explaining *why*. Python 3.10+ / shell only for tooling.
- UI copy bilingual (en/fr). Visitor-facing strings in `i18n.js` `PAGE`, editor strings in `EDITOR`.
- Update `README.md` (widget table, roadmap) when behaviour changes.
- Commits: imperative summary line; no new dependencies without discussing it first.
